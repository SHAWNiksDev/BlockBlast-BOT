BlockBlast BOT 0.4.0 — Windows и Linux.

Windows: распакуйте `BlockBlast-BOT-windows-x86_64.zip` целиком и запустите `BlockBlast BOT.exe`.
Linux: распакуйте `BlockBlast-BOT-linux-x86_64.tar.gz` и запустите `BlockBlast BOT` (glibc 2.39+).

Python и инструменты уже включены. Подключите телефон, подтвердите USB-отладку. На Windows может потребоваться драйвер производителя.

Личных профилей, кадров телефона и результатов игровых прогонов в поставке нет. Профиль по умолчанию пустой: поле ищется автоматически. Перед управлением телефоном проверьте распознавание и откалибруйте жесты. Универсальная работа с любым разрешением не гарантируется.

Поле и фигуры распознаются по изображению, OCR читает очки. Прямое чтение памяти игры не реализовано.

Настройка телефона теперь выполняется в интерфейсе: «Настроить телефон» → проверка поля и фигур → сохранение. Кнопка «1 ход» выполняет одно подтверждённое размещение и останавливается. Профиль хранится только локально.

Исправлено распознавание рамки поля и фоновых полос в пустых слотах. Добавлены тесты на сгенерированных изображениях. Физическое USB-подключение к Windows пока не проверено.
