# Изменения

## 0.4.0

- Добавлен мастер настройки телефона: снимок в памяти, ручное выделение областей, просмотр распознанного поля и фигур, сохранение локального профиля без идентификаторов устройства.
- Кнопка «1 ход» проверяет размещение без изменения обычного лимита партии.
- Улучшен поиск поля с яркой рамкой и распознавание уменьшенных кадров. Геометрия поля фиксируется на время сессии.
- Фоновые полосы в пустых слотах дополнительно проверяются по цвету и граням кубиков.
- Добавлены искусственно созданные сцены и проверки мастера настройки.
- Сообщения подключения различают отсутствие устройства, неподтверждённую отладку и состояние offline.

## 0.3.1

- Удалены профиль личного телефона, реальные снимки экрана и отчёты игровых прогонов.
- По умолчанию используется пустой профиль с автоматическим поиском поля; жесты необходимо проверить и откалибровать на своём устройстве.
- Проверка OCR в собранной программе использует сгенерированное изображение.
- Windows и Linux поставляются с Qt, ADB, FFmpeg, Tesseract и шрифтами интерфейса.
